\subsection{Normal Forecast: Trung bình trượt đơn giản (SMA)}
\label{sec:ch4-sma}
Thuật toán \textit{Normal Forecast} (\mintinline{javascript}{runForecast}, Mã nguồn~\ref{lst:sma}) áp dụng mô hình Trung bình trượt đơn giản (\textit{Simple Moving Average}) với kích thước cửa sổ trượt mặc định $N = 4$~\cite{hyndman2021forecasting}. Tại mỗi bước dự báo $i = 1, \dots, K$, giá trị dự báo $\hat{y}_{T+i}$ bằng trung bình cộng của $N$ phần tử cuối cùng trong chuỗi (gồm dữ liệu thực và các giá trị đã dự báo ở bước trước), làm tròn đến $2$ chữ số thập phân:
\begin{equation}
	\hat{y}_{T+i} = \text{round}_2\!\left(\dfrac{1}{|\mathcal{W}_i|}\displaystyle\sum_{y \in \mathcal{W}_i} y\right), \quad \mathcal{W}_i = h[\max(0, |h|-N) : |h|]
\end{equation}

\begin{listing}[H]
	\begin{minted}[fontsize=\footnotesize, linenos, breaklines]{javascript}
function runForecast(history, periods, windowSize = 4) {
  if (!Array.isArray(history) || history.length === 0 || !periods || periods <= 0) return [];
  const numPeriods = parseInt(periods, 10);
  if (isNaN(numPeriods) || numPeriods <= 0) return [];
  const effectiveWindow = Math.max(1, parseInt(windowSize, 10) || 4);
  const result = [];
  const h = history.map(v => Number(v) || 0);
  for (let i = 0; i < numPeriods; i++) {
    const window = h.slice(-effectiveWindow);
    const sum = window.reduce((acc, val) => acc + val, 0);
    const val = window.length > 0 ? sum / window.length : 0;
    result.push(Math.round(val * 100) / 100);
    h.push(val);
  }
  return result;
}
\end{minted}
	\caption{Thuật toán Normal Forecast (SMA) trong \texttt{backend/algorithms/forecast.js}}
	\label{lst:sma}
\end{listing}

\subsection{Super Forecast: WMA kết hợp hệ số mùa vụ}
\label{sec:ch4-wma}
Do dữ liệu bán lẻ có đỉnh mùa vụ rõ rệt vào tháng $8$ và tháng $12$ (Chương~\ref{part:ch2}), thuật toán \textit{Super Forecast} (\mintinline{javascript}{runForecastSuper}, Mã nguồn~\ref{lst:wma}) cải tiến theo hai bước:
\begin{enumerate}[label=\textit{\arabic*},topsep=0pt, itemsep=1pt]
	\item \textbf{Trung bình trượt có trọng số (WMA):} Gán trọng số tăng dần $w = [1, 2, 3, 4]$ cho $4$ kỳ gần nhất ($\sum w_j = 10$), giúp mô hình nhạy hơn với xu hướng mới phát sinh. Nếu chuỗi lịch sử có ít hơn $4$ phần tử ($L < 4$), thuật toán tự động cắt $L$ trọng số cuối của $w$ để tránh lỗi chia mảng không khớp.
	\item \textbf{Điều chỉnh theo hệ số mùa vụ ($SF_m$):} Với tháng dự báo $m = (\text{currentMonth} + i) \bmod 12$, hệ số mùa vụ được tính từ trung bình lịch sử của tháng đó ($\overline{y}_m$) chia cho trung bình toàn chuỗi ($\overline{y}$):
	      \begin{equation}
		      SF_m = \begin{cases}
			      \overline{y}_m / \overline{y}, & \text{nếu } \overline{y} > 0 \text{ và } \overline{y}_m > 0 \\
			      1,                             & \text{ngược lại}
		      \end{cases}, \qquad
		      \hat{y}^{\text{super}}_{T+i} = \text{round}_2(\text{WMA}_i \cdot SF_m)
	      \end{equation}
\end{enumerate}

\begin{listing}[H]
	\begin{minted}[fontsize=\footnotesize, linenos, breaklines]{javascript}
const baseWeights = [1, 2, 3, 4];
const currentMonth = new Date().getMonth();
for (let i = 0; i < numPeriods; i++) {
  const window = h.slice(-4);
  const activeWeights = baseWeights.slice(baseWeights.length - window.length);
  const activeTotalW = activeWeights.reduce((a, b) => a + b, 0);
  const wma = activeTotalW > 0
    ? window.reduce((s, v, j) => s + v * activeWeights[j], 0) / activeTotalW : 0;
  const forecastMonth = (currentMonth + i) % 12;
  const mAvg = (monthlyAvg && monthlyAvg[forecastMonth] != null)
    ? Number(monthlyAvg[forecastMonth]) : overallAvg;
  const sf = (overallAvg && overallAvg > 0) ? (mAvg || overallAvg) / overallAvg : 1;
  const val = Math.round(wma * ((!isNaN(sf) && sf > 0) ? sf : 1) * 100) / 100;
  result.push(val);
  h.push(val);
}
\end{minted}
	\caption{Trích đoạn thuật toán Super Forecast (WMA + Mùa vụ) trong \texttt{forecastsuper.js}}
	\label{lst:wma}
\end{listing}

Riêng ở mỗi nếp huấn luyện, các đột biến lễ hội vượt ngưỡng $1{,}25 \cdot \text{roll\_median\_4} + 1{,}0$ được kẹp chặn trên nhằm ổn định cây quyết định. Quy trình tìm kiếm lưới tham số (\textit{grid search} trên $4$ cấu hình qua hai kỳ \mintinline{python}|t_idx in {7, 8}|) lựa chọn mô hình \textit{HistGradientBoostingRegressor} tối ưu hàm mất mát phân vị (\mintinline{python}{loss='quantile'}, \mintinline{python}{quantile=0.42}, \mintinline{python}{max_depth=4}, \mintinline{python}{learning_rate=0.05}, \texttt{l2\_\allowbreak{}regularization=5.0}, \texttt{min\_\allowbreak{}samples\_\allowbreak{}leaf=30}, \mintinline{python}{max_iter=120})~\cite{friedman2001gbm}. Mô hình quán quân \textbf{\mintinline{text}{Hybrid_GBDT_Seasonal_Ensemble}} phối hợp tuyến tính ba kiến trúc bổ trợ nhau:
\begin{equation}
	\hat{y}_{\text{hybrid}} = 0{,}45\,\hat{y}_{\text{HistGBDT}} + 0{,}35\,\hat{y}_{\text{RandomForest}} + 0{,}20\,\hat{y}_{\text{RidgeCV}}
\end{equation}
trong đó \mintinline{python}{RandomForestRegressor} dùng $80$ cây (\mintinline{python}{max_depth=6}, \mintinline{python}{min_samples_leaf=25})~\cite{breiman2001rf}, còn \mintinline{python}{RidgeCV} chọn tham số điều chuẩn $\alpha = 1.000{,}0$ (trong lưới $[500; 1.000; 2.000; 5.000]$, \mintinline{python}{fit_intercept=False}) trên $8$ biến trễ cốt lõi để neo xu hướng khi dự báo đệ quy dài hạn (gắn điều kiện kẹp bằng $0$ khi $\text{sma\_4} \le 0$). Đánh giá mở rộng ngoài mẫu tại $4$ chân trời thời gian (\mintinline{python}{t_idx = 7, 8, 9, 10}, tổng cộng $4.320$ dự báo) được tổng hợp trong Bảng~\ref{tab:ml-forecast-benchmark}.

Dựa trên lý thuyết kiểm soát tồn kho theo số ngày bao phủ nhu cầu (\textit{days of supply})~\cite{silver2016inventory}, hàm \mintinline{javascript}{classifyInventory(qtyOnHand, avgDailySales)} (Mã nguồn~\ref{lst:classify}) đối chiếu lượng tồn hiện tại với tốc độ tiêu thụ bình quân $30$ ngày gần nhất ($\text{avgDailySales} = \text{sales30d} / 30$) theo luồng quyết định trong Hình~\ref{fig:inventory_classify_flow}.

\begin{listing}[H]
	\begin{minted}[fontsize=\footnotesize, linenos, breaklines, firstnumber=16]{javascript}
function classifyInventory(qtyOnHand, avgDailySales) {
  const qty = Number(qtyOnHand) || 0;
  const sales = Number(avgDailySales) || 0;
  if (sales <= 0) return 'healthy';
  if (qty >= sales * 60) return 'over';
  if (qty < sales * 14) return 'low';
  return 'healthy';
}

\begin{equation}
	p_{\text{low}} = \dfrac{1}{1 + \exp\!\bigl((\text{coverDays} - 14)/3{,}5\bigr)}, \quad
	p_{\text{over}} = \dfrac{1}{1 + \exp\!\bigl(-(\text{coverDays} - 60)/8{,}0\bigr)}
\end{equation}
với $p_{\text{healthy}} = \max(0{,}02,\ 1 - p_{\text{low}} - p_{\text{over}})$ chuẩn hóa trên tổng ba lớp. Đặc biệt, khi $\text{avgDailySales} \le 0$ và $\text{qty} > 0$, API trả về $\{p_{\text{healthy}}=0{,}88;\ p_{\text{low}}=0{,}04;\ p_{\text{over}}=0{,}08\}$ kèm cờ tường minh \mintinline{text}{isDeadStockCandidate = true} để cảnh báo $25{,}72\%$ hàng tồn không phát sinh doanh số.
